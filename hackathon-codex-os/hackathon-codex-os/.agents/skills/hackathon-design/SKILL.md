# Hackathon Design

1. Identify the one screen that visually proves the result and sketch its before/after hierarchy.
2. Select a restrained design system, readable contrast, generous spacing, mobile-friendly layout, obvious action state.
3. Include loading, error and empty data states; add a convincing but honest sample dataset if needed.
4. Verify the complete interaction, not just a screenshot. Keep changes isolated to UI/design files.
