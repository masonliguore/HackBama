# Hackathon Pitch

1. Build a timed 30-second hook, 2-minute demo, and 60-second technical explanation.
2. Lead with user pain, dramatic action, measurable output, and honest differentiation.
3. Prepare answers for novelty, technical difficulty, reliability, sustainability, security, and future work.
4. Update DEMO.md, README and submission assets. Check event requirements.
5. Rehearse entire live flow three times and produce a failure-safe recorded/local backup if rules allow.
