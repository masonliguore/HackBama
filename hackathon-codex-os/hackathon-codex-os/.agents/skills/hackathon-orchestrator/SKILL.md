# Hackathon Orchestrator

1. Read AGENTS.md and HACKATHON.md. Verify event rules and hard deadline with evidence when browsing is available.
2. Audit current project state and available development time. Delegate only independent tasks, with non-overlapping file ownership.
3. Use available Codex-native skills as needed: ideation/track strategy, architecture, simulation, build, design, QA/security, and pitch. The `agents/` role cards are reference prompts, not automatic independent agents; do not claim they are running in parallel.
4. Choose a P0 demo path, reserve the final 20–30% of time for verification, rehearsal, and submission; enforce freeze.
5. Check in at hours 3, 6, and 9; cut scope at hour 6 if the demo path is incomplete. Update PLAN.md, DECISIONS.md, DEMO.md, and PREPARATION_STATUS.md after meaningful steps.
6. Before claiming ready run python scripts/preflight.py and python scripts/demo_check.py plus real project checks.
