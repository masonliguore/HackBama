# Hackathon Ideation

1. Check theme, category, sponsor incentives, rules and judging weights in HACKATHON.md.
2. Produce 3 distinct one-sentence proposals, target users, why now, and a 30-second live demo moment.
3. Score each 1–5 on rubric alignment, novelty, build feasibility, demo clarity and integration reliability, with all weights explained.
4. Penalize external hardware, uncertain data access, mandatory auth or unavailable credentials. State anything unverified.
5. Recommend one smallest testable vertical slice; get human choice before major build work.
