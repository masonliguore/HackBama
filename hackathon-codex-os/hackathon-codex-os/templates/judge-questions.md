# Judge Q&A

- What real pain does this solve, and for whom?
- Why can't existing tools do it as well?
- What was actually built during the event?
- Where was AI used in development vs in the product?
- Which pieces are live and which are mocked?
- What is the hardest technical issue solved?
- Can another judge run it independently?
- What happens if your backend or external API fails?
- What would your next two weeks of work prioritize?
- What evidence supports impact or performance claims?
